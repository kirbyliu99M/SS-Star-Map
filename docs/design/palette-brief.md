## AGY 審查分析與推薦（未拍板 candidate，待 Owner 決定）

### 1. 現有三組與新增第四組分析

- **A 深海極光（Deep Sea Aurora）**：
  - **視覺與心理感受**：深海墨藍黑中浮現碧波薄荷極光，具有極高辨識度與生命力。
  - **語意分工優勢**：`accent`（#5EE6C5 冷極光綠）代表功能操作與按鈕，`starlight`（#F4C46A 暖金琥珀）代表星光、謝禮與連線。兩者在色相環上形成冷暖對比，使用者能一眼區分「系統互動」與「人情星光」，語意極為乾淨。
  - **對比度表現**：所有組合對比度高達 10:1 至 17:1，可讀性與抗視覺疲勞度居全組之冠。
  - **產品契合度**：「浮游」本身即帶有水生、漂浮、有機之意，墨綠海洋黑與極光綠能精準傳達「浮游星」的詩意。

- **B 墨紫燭光（Ink Purple Candlelight）**：
  - **視覺與心理感受**：深墨紫搭配燭光橙，氣質典雅、溫馨、具有文學與沙龍沙發氛圍。
  - **潛在隱憂**：`accent`（#F2A65A 暖橙）與 `starlight`（#FFE6A8 亮金）同屬暖黃橙色系。在小尺寸圖標、星圖節點或徽章上，容易讓使用者混淆「可點擊按鈕」與「人情星光」，色彩層次稍弱。

- **C 石墨珊瑚（Graphite Coral）**：
  - **視覺與心理感受**：純淨石墨黑搭配活潑珊瑚紅（#FF8466），當代設計感與潮流感最強。
  - **潛在隱憂**：風格偏向設計工作室或現代雜誌出版品，與 PRD §13.1 所描繪的「深空、星圖、星光漂浮」之宇宙意象連結較弱。

- **D 深空青金（Deep Cosmic Lapis）**：
  - **視覺與心理感受**：正統無垠的深夜藍天（Midnight Sky），最接近大眾對「星夜」的經典想像。
  - **語意分工優勢**：天藍（accent）與金珀（starlight）冷暖清晰，視覺穩定且耐看。若 Owner 與團隊希望避免 A 組的深海綠調，D 組是最佳的經典宇宙替代方案。

### 2. AGY 推薦排名

1. **第一推薦：A 深海極光（Deep Sea Aurora）**
   - **核心理由**：
     1. **語意最分明**：冷色互動（accent）vs 暖色星光（starlight），完全避免功能與情感標記的色彩衝突。
     2. **對比度全面封頂**：WCAG AAA 等級表現，長時間凝視星圖與個人網頁最舒適。
     3. **品牌隱喻最深**：完美演繹「浮游」與「星空」共融的有機社群感。

2. **第二備選：D 深空青金（Deep Cosmic Lapis）**
   - **核心理由**：經典午夜藍黑基調，最穩健不易出錯的星空視覺解方。

### 3. 待 Owner 拍板問題

1. **主色調定案**：是否同意採納 **A 深海極光** 為星夜主題的主配色（或偏好正統夜空的 **D 深空青金**）？
2. **多配色策略**：這三到四組配色是「擇一作為星夜唯一標準色」，還是未來作為星夜主題內的「可選色票氛圍」（即保留 Pencil 中的 `palette` 切換軸）？
3. **Pencil 與 Token 同步**：Owner 確認定案後，再由 Claude Code 驗算 D 組對比度，並同步寫入 Pencil 檔、`packages/themes/starry-night/tokens.css` 與 PRD 附錄 B。

**對 AGY 分析的修正**：
