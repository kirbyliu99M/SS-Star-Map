## 想請 AGY 特別看的地方

- 「請他幫忙」的語氣：太直接，還是剛好？是否該避免讓人覺得在「下單」。
- 雙語小標（英文小標＋中文大標，PRD §13.1）要不要保留；英文用詞是否自然。
- 可見度標籤「我的圈子」「公開」是否和 PRD §9.2 的可見度名稱一致。
- 跑馬燈標語「想得到 ✦ 找得到 ✦ 請得動」是否適合放在個人網頁（PRD 原本寫官網與開圈頁）。
