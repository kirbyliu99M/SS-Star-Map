## 想請 AGY 特別看的地方

- 「請他幫忙」的語氣：太直接，還是剛好？是否該避免讓人覺得在「下單」。
- 雙語小標（英文小標＋中文大標，PRD §13.1）要不要保留；英文用詞是否自然。
- 可見度標籤「我的圈子」「公開」是否和 PRD §9.2 的可見度名稱一致。
- 跑馬燈標語「想得到 ✦ 找得到 ✦ 請得動」是否適合放在個人網頁（PRD 原本寫官網與開圈頁）。

### AGY 審查回覆（未拍板 candidate，待 Owner 決定）

1. **關於「請他幫忙」的語氣**：
   - 語氣評估：確實稍嫌直接，且在華人的人際脈絡與熟人小圈子中，直接寫「請他幫忙」容易產生微弱的「任務外包下單感」或給人心理壓力。PRD §0 與 §2 原則 8 強調「人情記在心裡，不攤在桌上、不替幫忙開價」。
   - 建議修改方案：
     - **推薦方案 A：`✦ 向他請教`** —— 姿態尊重且心理門檻最低，非常符合同儕或前輩間交流的自然開場。
     - **推薦方案 B：`✦ 想請他幫忙`** —— 僅多加一個「想」字，即可將祈使句轉為意願表達，大幅淡化下單感，保留人情溫度。

2. **關於雙語小標（PRD §13.1）與英文用詞**：
   - 建議保留。雙語層次（英文小標＋中文大標）是 PRD §13.1 明定的星夜設計語言，能營造精緻、具國際質感的現代畫布感。
   - 英文用詞自然度：草稿中的 `PRODUCT STORYTELLER`、`OFFERS`、`ASKS`、`TIMELINE` 均為科技與新創社群常見且自然的道地詞彙，非常合適。
   - 排版形式建議：在畫面排版上，建議採用「上層英文 Overline（全大寫、小字、字距微寬）＋ 下層中文 H2 大標」的垂直堆疊排版，避免直接在同一行使用全形斜線「／」，視覺呼吸感會更佳。

3. **關於可見度標籤「我的圈子」「公開」的一致性**：
   - 與 PRD 完全一致：PRD §9.2 區塊目錄中定義的預設可見度正是「公開」與「我的圈子」，後端 enum（PRD §16.2）對應為 `public` 與 `circles`，名詞完全吻合。
   - 介面展示建議：目前草稿第 14 項並列為「我的圈子／公開」，在單一卡片上容易讓人誤以為是二選一的開關。在卡片角落的狀態 Badge 上，應顯示當下所屬的狀態（例如標記為「我的圈子 ✦」或「圈內限定」）；編輯狀態下才提供選擇器。

4. **關於跑馬燈標語「想得到 ✦ 找得到 ✦ 請得動」放在個人網頁的適合度**：
   - 結論：**不適合**放在個人的獨立網頁（`/@handle`）。
   - 原因：PRD §13.1 明文規定此跑馬燈是用在「官網與開圈頁」。依據 PRD §2 原則 7（美感是入口）與 §13.3（刻意不學 HypeLink 強制平台推廣宣傳），個人網頁應完全以「個人的作品、經歷與互助資源」為主角。在個人經歷與技能之間插入平台的行銷 Slogan，宣傳感過強，會破壞個人品牌美感。
   - 建議替代方案：
     - 方案 A（推薦）：個人網頁若需跑馬燈元件，改為「個人專長標籤跑馬燈」（如 `✦ 募資簡報 ✦ 故事線梳理 ✦ 簡報視覺 ✦`），兼顧動態視覺並回歸個人特質。
     - 方案 B：在個人網頁直接移除跑馬燈元件，回歸純淨的閱讀動線；標語專注於首頁 Landing Page 與開圈引導頁。
